# Глоссарий

## Модуль 1

- **Вещество** — то, из чего состоят физические тела.
- **Физическое тело** — отдельный предмет, имеющий форму и объём.
- **Свойство вещества** — признак, по которому вещества различают и описывают
  (цвет, запах, твёрдость, растворимость, горючесть и др.).
- **Наблюдение** — внимательное изучение явления без вмешательства в процесс.
- **Эксперимент** — изучение явления через активное воздействие на вещество.
- **Измерение** — сравнение величины с эталоном (получение числа).
- **Моделирование** — замена объекта упрощённой схемой для изучения.
- **Гипотеза** — разумное предположение, которое ещё нужно проверить экспериментом.
- **Лаборатория** — помещение со специальным оборудованием для опытов.

## Модуль 2

- **Агрегатное состояние** — состояние вещества (твёрдое, жидкое, газообразное) при данных условиях.
- **Плавление** — переход вещества из твёрдого состояния в жидкое при нагревании.
- **Кипение** — переход жидкости в газ по всему объёму при температуре кипения.
- **Конденсация** — переход вещества из газообразного состояния в жидкое при охлаждении.
- **Замерзание** — переход жидкости в твёрдое состояние при охлаждении.
- **Сублимация** — переход вещества из твёрдого состояния сразу в газообразное, минуя жидкость.
- **Чистое вещество** — вещество, состоящее из одинаковых частиц.
- **Смесь** — система из разных веществ (разных частиц), сохраняющих свои свойства.
- **Гомогенная смесь** — однородная смесь, составные части неразличимы глазом.
- **Гетерогенная смесь** — неоднородная смесь, части различимы.
- **Отстаивание** — разделение смеси по разной плотности: тяжёлое оседает.
- **Фильтрование** — разделение через пористую перегородку: твёрдое задерживается.
- **Выпаривание** — выделение растворённого вещества удалением растворителя нагреванием.
- **Дистилляция** — разделение жидкостей по разным температурам кипения.
