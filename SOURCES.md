# SOURCES.md — источники

Пока заглушка. У учеников есть свои учебники, отдельный список литературы не ведём.

- Базовый учебник для сверки терминов и порядка: Ерёмин (глоссарий — `data/glossary.md`).
- Цвета и радиусы атомов: CPK-раскраска, ковалентные радиусы (`data/elements.json`,
  зеркало `SIMULATIONS.md` §2).
- Видео/иллюстрации: подборки автора, вставки — через `.video-slot` (`DESIGN.md` §3.3).

При появлении внешних заимствований (видео, схемы) — фиксировать здесь:
что, откуда, ссылка.
