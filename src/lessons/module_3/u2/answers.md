# Ответы · Модуль 3 · Урок 2. Пять признаков химических реакций

Для учителя. В урок не встраивается.

## Пять признаков
1. **Выделение газа** — пузырьки, шипение (сода + уксус).
2. **Образование осадка** — помутнение, хлопья на дне.
3. **Изменение цвета** — раствор меняет окраску, появляется налёт.
4. **Выделение тепла** — смесь или посуда нагреваются.
5. **Выделение света** — пламя, свечение.

## Важно
- Один опыт может показывать **сразу несколько** признаков (горение свечи — тепло и свет).
- Изменение **формы** — это НЕ признак реакции (это физическое явление).

## Термины
признак реакции · осадок · выделение газа · изменение цвета · экзо/эндо (см. урок 3).

## В тетрадь
Опиши один домашний опыт (например, гашение соды уксусом) и назови признаки реакции, которые ты наблюдал.
