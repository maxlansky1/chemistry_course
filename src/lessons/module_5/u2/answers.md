# Ответы · Модуль 5 · Урок 2. Модели атома

Для учителя. В урок не встраивается.

## Как менялись модели
1. **Демокрит** — идея неделимых частиц (атомов).
2. **Томсон** — «пудинг с изюмом»: электроны в положительном шаре.
3. **Резерфорд** — опыт с золотой фольгой: в центре — маленькое **ядро**, вокруг — электроны.
4. **Бор** — электроны движутся по **орбитам** с определённой энергией (кванты).
5. **Квантовая модель** — электрон — это «облако вероятности», а не точка на орбите.

## Главное
Каждая новая модель лучше объясняла эксперименты — наука развивается через уточнение.

## В тетрадь
Нарисуй модели Томсона и Резерфорда и подпиши, чем они отличаются.
