# Ответы · Модуль 2 · Урок 2. Переходы и смеси

Для учителя. В урок не встраивается.

## Симуляция «график нагрева»
- Плато при 0 °C — плавление, при 100 °C — кипение.
- На плато температура постоянна, вещество меняет состояние.

## Игра «чистое / гомогенная / гетерогенная»
- Чистые: дистиллированная вода, чистое золото, алмаз, чистая соль.
- Гомогенные: воздух, раствор сахара, спирт+вода, уксус.
- Гетерогенные: песок с опилками, молоко, гранит, вода с глиной.
