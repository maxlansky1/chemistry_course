# Ответы · Модуль 2 · Урок 3. Разделение смесей

Для учителя. В урок не встраивается.

## Практикум «очистка соли» (4 вопроса)
1. Начать — **растворить смесь в воде**.
2. Дальше — **отфильтровать**.
3. С раствором — **выпарить воду**.
4. В конце — **убрать рабочее место, вымыть руки, записать наблюдения**.

## Игра «способ разделения»
- Песок+вода, чай, мел+вода, соль+перец → фильтрование.
- Соль+вода, морская вода, сахарный сироп → выпаривание.
- Железо+сера, опилки+песок → магнит.
- Спирт+вода, дистилляция → дистилляция.
- Масло+вода → отстаивание. Чернила, пигменты листа → хроматография.
