# Ответы · Модуль 2 · Урок 1. Агрегатные состояния вещества

Для учителя. В урок не встраивается.

## Симуляция «агрегатные состояния»
- Лёд (≤0 °C): плотная упаковка, колебания около решётки.
- Вода (0–100 °C): движутся, но в объёме, есть поверхность.
- Пар (≥100 °C): свободный полёт по всему сосуду.
