# Ответы · Модуль 2 · Итоговый тест

Для учителя. 15 вопросов, порог 80% — 12 из 15. В урок не встраивается.

1. Три состояния — **твёрдое, жидкое, газообразное**.
2. При переходе твёрдое→жидкое — **частицы движутся свободнее, часть связей разрушается**.
3. Плавление — **переход из твёрдого в жидкое**.
4. Газ → жидкость — **конденсация**.
5. Сублимация — **переход из твёрдого в газ, минуя жидкое**.
6. Плато на графике — **температура не меняется: энергия уходит на разрушение связей**.
7. Чистое вещество — **из частиц одного вида**.
8. Смесь — **из двух и более разных компонентов**.
9. Воздух — **гомогенная смесь газов**.
10. Гетерогенная смесь — **видны границы между компонентами**.
11. Песок+вода — **фильтрованием**.
12. Соль из морской воды — **выпариванием**.
13. Железные опилки+сера — **магнитом**.
14. Спирт+вода — **дистилляцией**.
15. При физическом разделении — **вещества остаются теми же**.

Проверка: ученик показывает экран результата (скриншот автору).
