# Ответы · Модуль 1 · Урок 3. Лаборатория: безопасность и оборудование

Для учителя. В сам урок не встраивается.

## Вопросы QA (hero)
1. **Как работать в лаборатории безопасно?** — Халат, очки, не пробовать на вкус, нюхать ладонью, работать по инструкции, убирать за собой.
2. **Как называется оборудование и зачем оно?** — Пробирка (малые опыты), колба (смешивание/нагревание), мензурка (объём), весы (масса), спиртовка (нагрев), шпатель, чашка Петри, термометр, воронка/фильтр.
3. **Как описать вещество по плану?** — Цвет и блеск → запах → твёрдость → растворимость → горючесть.

## Практикум (5 вопросов)
1. Цвет и блеск меди — **рыжая, с металлическим блеском**.
2. Запах чистой воды — **нет запаха**.
3. Самое твёрдое — **алмаз**.
4. Растворяется в воде — **сахар**.
5. Горит — **спирт**.

## Сценарии безопасности (основное)
- Разбил пробирку → сообщить учителю, убрать щёткой/совком, не руками.
- Кислота на коже → сначала снять насухо салфеткой, затем промыть водой, сообщить учителю.
- Понюхать вещество → направлять пары ладонью, не наклоняться к сосуду.

## Фейнман (в тетрадь)
- **Объясни младшему, почему нельзя пробовать вещества на вкус.** Ход: в лаборатории даже «знакомое» вещество может быть грязным/ядовитым; правила защищают всех.
