# STRUCTURE.md — словарь структуры проекта

Источник правды по папкам, файлам и именам. Правится при любом добавлении папки,
модуля или урока. Связи: `PROGRAM.md` (уровни), `DESIGN.md` (каркас и компоненты),
`SIMULATIONS.md` (сущности симов).

---

## 1. Дерево

```
chemistry_course/
├── PROGRAM.md            # скелет программы (уровни A–F, модули, принципы)
├── DESIGN.md             # дизайн-система
├── SIMULATIONS.md        # визуальные сущности
├── STRUCTURE.md          # этот словарь
├── SOURCES.md            # источники (пока заглушка)
├── .gitignore            # .env, dist/, мусор — в git не едут
├── .env                  # токен бота (только локально)
│
├── data/
│   ├── glossary.md       # термин → определение, сверка с Ерёминым
│   └── elements.json     # CPK-таблица как данные (зеркало SIMULATIONS.md §2)
│
├── modules/              # уроки (фаза ручной сборки)
│   ├── mod01/            # Модуль 1. Химия как наука
│   │   ├── u1.html       # урок 1 (+ разогрев М1 внутри)
│   │   ├── u2.html
│   │   ├── u3.html
│   │   └── final.html    # итоговый (входного у М1 нет)
│   ├── mod02/            # Модуль 2. Агрегатные состояния и смеси
│   │   ├── entry.html    # входной 10 вопросов
│   │   ├── u1.html … uN.html
│   │   └── final.html
│   ├── mod03a/ mod03b/ mod04a/ mod04b/  # та же схема
│   └── legacy/           # старые файлы как есть, до миграции каждого
│
├── src/                  # фаза Б (билдер): фрагменты + манифесты уроков
│   ├── shared/           # ядро css/js, ChemDraw, движок, пульт
│   └── build.py          # манифест → автономный HTML
│
└── dist/                 # собранные файлы для рассылки (в git не едет)
```

## 2. Правила имён

Только английский, lowercase, без пробелов: `modNN` (модули; сплиты — `mod03a`),
`uN` (уроки внутри модуля с 1), `entry.html`, `final.html`.
Кириллицы, заглавных, пробелов в именах нет — человеческие названия живут
внутри файлов (hero) и в карте §3.

## 4. Анатомия урока (порядок блоков)

hero-мини (крошки `Уровень → Модуль → Урок k из N` + время ~15–20 минут + QA-карточки
из `module.json`, рендерит билдер)
→ теория → интерактив → практикум (+ `.notebook-task`)
→ кусок Фейнмана-в-тетрадь → `.thinker` → `.recap-card` → `.homework` (5+ задач)
→ навигация `.lesson-nav` (генерирует билдер из `module.json`, без упоминаний файлов).
В уроке нет: входного, итогового, отдельного блока «как учимся».

Файлы модуля: `entry.html` (входной, конфиг `entry`), `final.html` (конфиг `final`).
Выжимка модуля (сборка из выжимок уроков) — позже, делает билдер.

## 5. Конвенция ссылок (без роутера)

Относительная ссылка + обязательный текстовый дубль с полным путём:
`<a href="u2.html">Дальше →</a>` и рядом «Дальше: открой файл `mod01/u2.html`».
Ссылка — удобство (десктоп), текст — гарантия (телефон).

## 6. Конвенция глоссария

Термин из `data/glossary.md` при первом появлении в уроке — синяя пометка
(`callout-note` или инлайн-класс позже). Нового термина нет в глоссарии —
сначала строка в глоссарий, потом использование.
