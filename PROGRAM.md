\# 🧪 Единый непрерывный курс химии: от нуля до конца неорганики



\## Философия курса



Вы хотите \*\*не курс для 7, 8, 9 класса\*\*, а \*\*единый учебник химии\*\*, который ученик открывает с любой точки и осваивает последовательно. Это \*\*mastery-based learning\*\* — обучение на основе мастерства, а не по расписанию.



\*\*Ключевые принципы:\*\*

1\. \*\*Строгая линейность:\*\* Каждый модуль опирается только на предыдущие. Нет «перепрыгиваний».

2\. \*\*Модульность:\*\* Каждый модуль — это законченный блок с теорией, практикой, тестом и рефлексией.

3\. \*\*Вход с любой точки:\*\* Если ученик уже знает базу, он проходит входной тест и начинает с нужного модуля.

4\. \*\*Мастерство как пропуск:\*\* Нельзя перейти к следующему модулю, пока не сдал текущий (порог — 80%).

5\. \*\*Три уровня Джонстона — с Модуля 4б.\*\* До этого треугольник не упоминается вообще: Модули 1–2 идут на макроуровне, Модуль 3 впервые касается субмикро без формул. В Модуле 4б треугольник вводится как новое понятие и с этого момента становится рабочим инструментом: каждый блок маркируется 👁/⚛️/🔢, от ученика требуется перевод между уровнями.

6\. \*\*Метод Фейнмана — в тетрадь.\*\* После каждого модуля ученик объясняет тему своими словами (обращение — «объясни сыну/дочке/брату/сестре», ядро аудитории — 7–9 классы, язык при этом универсальный) и записывает в тетрадь. Проверяет учитель лично. Сохранения текста в HTML нет.

7\. \*\*Тон — один для всех, примеры — в два слоя.\*\* Рассказчик нейтральный («давай разберёмся»), а примеры даются парами: бытовой (кухня, дом) + взрослый/прикладной (медицина, производство). Никто не чувствует, что текст «не для него».

8\. \*\*Нумерация модулей условна.\*\* Модули уже дробятся по факту (3а/3б, 4а/4б) и будут дробиться дальше. Карта ниже — набросок, правится по мере разбиения.

9\. \*\*Три уровня контента: уровень → модуль → урок.\*\* Уровень (A–F) — ступень программы. Модуль объединяет уроки. Урок — один файл на 15–20 минут, единица рассылки. Входной и итоговый тесты живут на уровне модуля отдельными файлами (`entry.html`, `final.html`). Вся структура, имена файлов и правила — в `STRUCTURE.md`.

Потолок курса — конец неорганики. Органика — вне скоупа.

\## 🔄 СИСТЕМА ВХОДА С ЛЮБОЙ ТОЧКИ



Каждый модуль (кроме Модуля 1) начинается с \*\*входного теста из 10 вопросов\*\* строго по пререквизитам предыдущего модуля. Если ученик набирает \*\*>80%\*\*, он может перейти к следующему модулю. Если нет — проходит модуль полностью.

Модуль 1 входного теста-гейта не имеет (пререквизитов нет): вместо него — \*\*5 вопросов-разогревов без оценки\*\* («проверь себя, что ты уже знаешь»).

Безопасность — исключение из правила 80%: блок безопасности сдаётся на \*\*100% (все сценарии верно)\*\*, иначе дальше не идём.

\## 🧩 СТРУКТУРА КАЖДОГО МОДУЛЯ (HTML-урок)



1\. \*\*Входной тест\*\* (10 вопросов по пререквизитам; в Модуле 1 — 5 разогревов без оценки)

2\. \*\*Теоретический блок\*\* (текст + встроенные визуализации; маркировка Джонстона — только с Модуля 4б; опциональные скрытые заглушки под видео YouTube/Instagram — если видео нет, блок скрыт и вёрстка не едет)

3\. \*\*Интерактивный блок\*\* (игры, симуляции, drag-and-drop)

4\. \*\*Практический блок\*\* (виртуальная лаборатория, задачи)

5\. \*\*Рефлексия по Фейнману\*\* (пометка «Объясни своими словами и запиши в тетрадь», проверяет учитель; выбора готовых вариантов здесь нет — только собственное объяснение)

6\. \*\*Итоговый тест\*\* (порог 80%)

7\. \*\*Задачка на подумать★\*\* (один интересный вопрос по теме урока, без ответа в файле — разбирается на уроке)

8\. \*\*Карточка-выжимка\*\* (по практике учебника Ерёмина: 5–7 тезисов + новые термины с определениями в одну строку; формулы — если изучались, отдельным красиво выделенным блоком)

\*\*Время:\*\* трудоёмкость указывается в шапке каждого HTML-файла и разбивается по сессиям внутри (швы-паузы «дальше — перерыв, зафиксируй в тетради»). Файлы — интерактивные конспекты: на уроке учитель ведёт по ним через tldraw, дома ученик повторяет; параллельно ученик ведёт тетрадь и школьные материалы.

\## 📊 ПОЧЕМУ ЭТО РАБОТАЕТ



| Проблема традиционной программы | Решение в вашем курсе |

|---|---|

| Жесткая привязка к классам | Модули, а не классы |

| Нельзя догнать пропущенное | Вход с любой точки + пререквизиты |

| Нет мотивации | Мастерство как пропуск + мгновенная обратная связь |

| Абстрактность | Джонстон + виртуальные лаборатории |

| Заучивание без понимания | Метод Фейнмана |

| Разрыв между теорией и практикой | Каждый модуль = теория + практика + рефлексия |
