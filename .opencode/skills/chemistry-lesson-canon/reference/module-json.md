# Схема `module.json`

Один файл на модуль: `src/lessons/<module>/module.json`. Сборщик читает его и
рендерит то, что **не** пишется в `body.html` (введение, практикум, ДЗ, шапки).

## Верхний уровень (модуль)

| Ключ | Тип | Обяз. | Смысл |
|---|---|---|---|
| `id` | string | да | `module_N` |
| `title` | string | да | `Модуль N. Название` |
| `badge` | string | да | `Модуль N · Название · ~X` |
| `digest` | string | да | 1–2 предложения о модуле |
| `canon` | string | да | версия канона, обычно `"1.0"` |
| `order` | string[] | да | порядок файлов: `["entry","u1",…,"final"]` (может не быть `entry`) |
| `lessons` | object[] | да | мета уроков (см. ниже) |
| `intro` | object | да | **модульное** введение (см. ниже) |

### `intro` модуля

```json
{
  "subtitle": "Три урока о том, …",
  "lead": "Абзац-lead с риторическими вопросами.",
  "cards": [
    { "icon": "🧪", "title": "Тезис", "desc": "Вопрос или пояснение." }
  ],
  "callout": "Идея-аналогия модуля (одно-два предложения)."
}
```

2–5 карточек. `callout` — у модульного введения (рендерится как `callout-idea`).

## Урок (элемент `lessons[]`)

| Ключ | Тип | Обяз. | Смысл |
|---|---|---|---|
| `file` | string | да | `u1`, `u2`, … (совпадает с папкой) |
| `title` | string | да | `Урок K. Название` |
| `chip` | string | да | `Урок K` |
| `pill` | string | да | `"1"`, `"2"`, … |
| `time` | string | да | `~20 минут` |
| `intro` | object | да | **урочное** введение: `{ "lead": "…", "cards": [ … ] }` |
| `homework` | object | да | `{ "subtitle": "…", "tasks": ["…"], "feynman": ["…"] }` |
| `practical` | object | да | `{ "title", "lead", "materials": [], "steps": [], "safety", "record" }` |
| `css` | string[] | нет | напр. `["core"]`; **можно не указывать** |
| `js` | string[] | нет | движки интерактива; **можно не указывать** |
| `topics` | string[] | нет | теги (опционально) |

- Если `css`/`js` **не указаны**, сборщик сам подберёт движки по классам в `body.html`.
  Это надёжнее — предпочтительно не указывать.
- `homework.tasks` — 4 задачи + одна со `★`; `feynman` — 1–2 задания «объясни
  простыми словами». Рендерится в блоке ДЗ, **в HTML не дублируется**.
- `practical` — универсальный практикум; рендерится в `stage s-prac`, тоже **не в HTML**.

## Полный пример записи урока

```json
{
  "file": "u1",
  "title": "Урок 1. Как родилась химия",
  "chip": "Урок 1",
  "pill": "1",
  "time": "~20 минут",
  "intro": {
    "lead": "Прежде чем изучать вещества, разберёмся, откуда взялась химия.",
    "cards": [
      { "icon": "⚗️", "title": "Алхимия", "desc": "Что искали алхимики?" },
      { "icon": "🔬", "title": "Наука", "desc": "Когда химия стала наукой?" }
    ]
  },
  "homework": {
    "subtitle": "Минимум 5 задач · письменно в тетрадь · проверяет учитель",
    "tasks": [
      "Задача 1 …",
      "Задача 2 …",
      "Задача 3 …",
      "Задача 4 …",
      "★ Вопрос со звёздочкой (без ответа)."
    ],
    "feynman": [
      "Объясни младшему брату, чем алхимия отличается от химии, простыми словами."
    ]
  },
  "practical": {
    "title": "Наблюдение и опыт",
    "lead": "Опыт отличается от наблюдения тем, что мы сами задаём условия.",
    "materials": ["вода", "стакан", "ложка"],
    "steps": ["Шаг 1 …", "Шаг 2 …"],
    "safety": "Не пробовать вещества на вкус без разрешения учителя.",
    "record": "Записать, что наблюдали и какой вывод сделали."
  }
}
```
