# Тесты и интерактивы

## Тесты (quiz)

Разметка — всегда пара: **div-контейнер** + **JSON-островок** с данными.

```html
<div id="quiz-u1-warmup" data-config="warmup"></div>
<script type="application/json" id="quiz-u1-warmup-data">
{
  "config": "warmup",
  "target": "quiz-u1-warmup",
  "questions": [
    {
      "type": "single",
      "q": "Что изучает химия?",
      "options": ["Только живые организмы", "Вещества, их свойства и превращения", "Только звёзды"],
      "correct": 1,
      "why": "Химия — наука о веществах, их свойствах и превращениях."
    }
  ]
}
</script>
```

Правила формата:
- `id` островка = `id` div + `-data`; `target` = `id` div.
- В островке **строго валидный JSON** (без комментариев, без висячих запятых).
- У каждого вопроса: `q`, `why` (непустой), минимум 2 варианта, корректный `correct`.
- Никакого JS писать не нужно — движок `quiz.js` подхватится по классу/островку.

### Конфигурации (`config`)

| config | Вопросов | Порог | Когда |
|---|---|---|---|
| `warmup` | 5 | — | разогрев, без оценки |
| `entry` | 10 | 80% | входной тест по пререквизитам |
| `practice` | по теме | — | разбор после темы/опыта |
| `final` | выборка из банка | 80% | итоговый тест модуля |
| `safety` | 5 | 80% | блок безопасности (на 100%) |

Порог везде 80% (кроме `warmup`); **без полбалла**; повторы неограниченны.

### Типы вопросов

- **`single`** — один правильный: `options: [string]`, `correct: <индекс>`. Основной тип.
- **`multi`** — несколько правильных: `correct: [индексы]`.
- **`match`** — сопоставление: слева элементы из данных, справа `options`, `correct`
  задаёт соответствие.

Пока в курсе используются только `single`; если не уверен в схеме `multi`/`match` —
делай `single` (разбей вопрос при необходимости).

## Другие интерактивы (игры, сценарии, таймлайны, оборудование)

Это тоже компоненты из `reference/components.md` (напр. `dropgames`, `scenarios`,
`timeline`, `sciences`, `equip`). У каждого — своя разметка-хук и часто свой
JSON-островок с данными. **Свой JS не пиши.** Точную разметку бери:

1. из `reference/components.md` (пример компонента), и
2. из приложенного готового примера урока (повтори его паттерн).

Если для нужного интерактива нет примера в приложенном уроке и непонятна разметка —
не изобретай: сделай обычный блок текста/`.callout` и отметь это в отчёте.
