# Правила и самопроверка

## Жёсткие правила

1. **Классы** — только из `reference/components.md`. Нет класса — используй ближайший
   существующий (`.callout`, `.prose`, `.card-grid`). Изобретать классы нельзя.
2. **Без инлайн-стилей.** Атрибут `style="…"` запрещён (ошибка линта). Всё оформление —
   классами.
3. **Баланс тегов.** Число `<div>` = числу `</div>`, `<section>` = `</section>`.
4. **Фрагмент, не документ.** `body.html` начинается с `<header class="hero">`.
   Никаких `<html>`, `<head>`, `<body>`, `<script src>`, `<link>`.
5. **Офлайн.** Никаких внешних ссылок/CDN/iframe (кроме `.video-slot`, только если дано).
6. **Тесты** — JSON-островком (`reference/quiz.md`), валидный JSON, порог 80%,
   `why` у каждого вопроса. Свой JS не писать.
7. **Введение, практикум, ДЗ — только в `module.json`.** В HTML не дублировать.
8. **L1 модуля — исторический** (кто/как придумал, откуда понятия).
9. **Каждый урок:** теория + практика (через `module.json`) + ДЗ (через `module.json`).
10. **Задачка★** (`.thinker`) — один вопрос, **без ответа** в файле.
11. **Выжимка** (`.recap-card`) — 5–7 тезисов; формулы (если были) — отдельно.
12. **Не забегать вперёд.** Не вводи термины из `not_yet`, если он задан во входе.
13. **Язык и тон** — русский, как в приложенном примере. Примеры парами:
    бытовой + взрослый/прикладной.
14. **Симуляции** — только слот (`reference/simulations.md`).

## Обязательная самопроверка перед отдачей

- [ ] `body.html` начинается с `<header class="hero">`, нет обёртки документа.
- [ ] Все классы есть в `reference/components.md` (могу перечислить использованные).
- [ ] Нет ни одного `style="`.
- [ ] `<div>`/`</div>` и `<section>`/`</section>` сбалансированы.
- [ ] Каждый JSON-островок — валидный JSON; `id` = div-id + `-data`.
- [ ] Тесты: порог 80% где положено, у каждого вопроса непустой `why`.
- [ ] Введение/практикум/ДЗ не продублированы в HTML.
- [ ] Урок исторический (если это L1), с теорией, реальной задачей, ★ и выжимкой.
- [ ] Нет внешних ресурсов и своего JS (кроме данных в островках).
- [ ] Заполнена запись `module.json` (title/chip/pill/time/intro/homework/practical).

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| `style="color:red"` | класс из каталога |
| `<div class="my-card">` | только классы из `components.md` |
| Вступление продублировано в HTML | оно уходит в `module.json` → `intro` |
| Тест как `<script>` с логикой | данные в JSON-островке, логику даёт `quiz.js` |
| `correct: "b"` | `correct: 1` (индекс) для `single` |
| Висячая запятая в JSON | строгий JSON без комментариев/запятых |
| Свой canvas/анимация | слот-заглушка для симуляции |
| Заголовок `<h1>` внутри теории | заголовки секций — `.stage-title`, а не `<h1>` |
