# Симуляции

**Статус: движки ещё не готовы (план P2).** Общая обёртка `makeSim(opts)` и ядро
рисования `ChemDraw` только запланированы, реестр — `src/shared/data/sims.json`.

Поэтому в этом скилле:

- **Не пиши** canvas, `requestAnimationFrame`, свой JS, `<canvas>`-логику.
- **Не изобретай** разметку симуляции.
- Если по теме нужна симуляция — вставь **текстовую заглушку-слот** обычным callout
  и перечисли нужный сим в отчёте:

```html
<div class="callout callout-note">
  🔮 Симуляция: «Агрегатные состояния» — здесь ученик будет менять температуру
  и наблюдать переходы. (Слот: движок появится позже.)
</div>
```

- В `module.json` / `body.html` **не** добавляй `css`/`js` под симуляции.

Когда движки появятся, к этому скиллу добавится отдельный раздел с точной разметкой
`makeSim`/`ChemDraw`; пока — только слот.

Компоненты с id, начинающимися на `sim-` (напр. `sim-atom-evidence`,
`sim-conservation`, `sim-atom-models`), в `components.json` есть, но это задел прошлых
версий — **не использовать** без отдельного указания.
