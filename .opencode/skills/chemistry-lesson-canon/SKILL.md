# Генерация файлов урока (канон курса химии)

Самодостаточная инструкция для агента-генератора. По теме урока и приложенному
готовому примеру ты выдаёшь файлы, которые автор положит в репозиторий.
Доступа к репозиторию у тебя нет — весь канон внутри этого скилла.

## Что должно быть на входе

1. **Модуль:** `module_N` и его название («Модуль N. …»), сколько всего уроков в модуле.
2. **Урок:** идентификатор `uX`, позиция (L1 — исторический), заголовок, тайминг (~20 минут).
3. **Глубина и запреты:** что можно вводить, а что **нельзя** (`not_yet`) — список терминов.
4. **Содержание:** тема, тезисы, реальная задача, идеи интерактива.
5. **Прикреплённый готовый пример** (`body.html` + `module.json`) — образец стиля, тона и блоков. Повторяй его.

## Что ты отдаёшь (ровно два артефакта)

1. **`body.html`** — фрагмент содержимого урока (см. `reference/skeleton.md`).
2. **Фрагмент `module.json`** — запись урока (и, если нужно, запись модуля) по
   `reference/module-json.md`.

`lesson.md` **не пиши** — его экспортирует репозиторий автоматически из `body.html`.

## Порядок работы

1. Изучи приложенный пример: структуру, классы, тон, длину абзацев.
2. Собери `body.html` строго по порядку каркаса (`reference/skeleton.md`).
3. Классы бери **только** из `reference/components.md`. Неизвестный класс = ошибка.
4. Тесты/игры — данными в JSON-островке (`reference/quiz.md`), не своим JS.
5. Заполни запись `module.json`: `title/chip/pill/time/intro/homework/practical`
   (`reference/module-json.md`). Введение, практикум и ДЗ **в HTML не дублируй**.
6. Прогони чек-лист из `reference/rules.md` и только потом отдавай файлы.

## Жёсткие правила (кратко, подробно — `reference/rules.md`)

- Язык — русский, тон — как в примере. Примеры давай парами: бытовой + прикладной.
- Только канонические классы; **никаких** `style="…"`; баланс `<div>`/`<section>`.
- Тесты: JSON-островок, порог 80%, без полбалла, у каждого вопроса непустой `why`.
- L1 модуля — исторический. Каждый урок: теория + практика + ДЗ.
- Задачка★ (`.thinker`) — без ответа. Выжимка (`.recap-card`) — 5–7 тезисов.
- Не забегай вперёд: не вводи термины из `not_yet`.
- Симуляции — только слот/заглушка, свой JS не писать (`reference/simulations.md`).

## Чего НЕ делать

- Не изобретать классы, id движков, компоненты.
- Не включать `<html>`, `<head>`, `<body>`, `<header>`-обёртку shell, `<script src>` — это добавит сборщик.
- Не помещать в HTML введение, практикум и домашнее задание.
- Не выдумывать внешние ссылки/CDN — файл обязан быть офлайн.
